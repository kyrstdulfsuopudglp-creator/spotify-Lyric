# Spotify Desktop Lyrics для KDE Plasma 6

Красивый нативный виджет для KDE Plasma 6, отображающий трек и синхронизированные тексты из Spotify. 

## Текст отображаеться даже если самого текста в Spotify нету.
Потому-что текст берётся напрямую из открытой базы данных текстов lrclib.net по названию трека и исполнителю.
## Установка
```bash
git clone https://github.com/kyrstdulfsuopudglp-creator/spotify-Lyric.git && cd spotify-Lyric
chmod +x install.sh
./install.sh
```
